# Node.js Study Notes

These are my personal study notes from learning Node.js and using JavaScript outside the browser. I am collecting the core runtime concepts, built-in APIs, and practical patterns that I want to understand and revisit while studying and working.

## About these notes

The chapters move from the Node.js runtime and command line into modules, npm, asynchronous work, events, files, streams, HTTP, process behavior, testing, and production practices. Each chapter will explain the purpose of a concept, show focused JavaScript examples, and end with review questions.

The examples use JavaScript and Node.js built-in modules unless a chapter explicitly introduces a package. Check the official Node.js documentation for version-specific behavior, and run examples with a supported Node.js release.

## Core topics

- Explain what Node.js provides and how JavaScript runs in a Node process
- Use the command line, scripts, and REPL
- Organize code with CommonJS and ECMAScript modules
- Read package metadata and manage npm dependencies
- Understand asynchronous I/O and event-loop behavior
- Work with events, files, paths, URLs, buffers, and streams
- Create HTTP services and handle request data
- Handle errors, process signals, and configuration safely
- Use child processes and worker threads for separate work
- Write tests with Node.js built-in tools
- Apply security, performance, and deployment practices

## How I use these notes

I use small examples that can be run locally, then change the input and observe what happens. For server and file-system examples, I keep test data disposable and avoid placing secrets in source files. The review questions help me check that I can describe each idea and choose the right API for a real task.
